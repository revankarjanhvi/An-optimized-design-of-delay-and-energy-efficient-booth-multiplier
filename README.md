# An-optimized-design-of-delay-and-energy-efficient-booth-multiplier

## Overview
This project implements an **Optimized Booth Multiplier** designed to reduce
**delay, power consumption, and hardware complexity** compared to conventional
multipliers. Booth encoding minimizes the number of partial products, making the
design efficient for high-performance digital systems.

## Objective
- Reduce multiplication delay
- Improve energy efficiency
- Optimize hardware resource usage
- Implement an efficient signed multiplication algorithm

## Description
The Booth Multiplier uses **Booth Encoding** to handle signed binary numbers by
encoding the multiplier bits and generating fewer partial products. The optimized
architecture improves speed and power efficiency, making it suitable for
**DSP, processor, and VLSI applications**.

## Key Features
- Signed multiplication support
- Reduced number of partial products
- Optimized for delay and power
- Suitable for FPGA and ASIC implementation
